# Synthetic datasets (CaDrift)

This folder contains the 20 synthetic datasets (B1-B20) used in Section 6.1 of the paper, generated with [CaDrift](https://github.com/eduardovlb/CaDrift) (Barboza et al., 2026) via the causal-graph generator invoked in `sintetico.py`.

## CaDrift dependency

CaDrift is released under the MIT License by its authors. It is **not** a pip-installable package (no `setup.py`/`pyproject.toml`), so it must be cloned locally and imported from the cloned folder, following the usage pattern in the [official repository](https://github.com/eduardovlb/CaDrift):

```bash
conda env create -f environment-synthetic.yml
conda activate cadrift-synthetic

git clone https://github.com/eduardovlb/CaDrift.git
cp -r CaDrift/SCM ./SCM   # place the SCM/ folder alongside sintetico.py

python sintetico.py
```

`environment-synthetic.yml` pins the dependencies declared in CaDrift's own `requirements.txt` (`numpy`, `pandas`, `matplotlib`, `networkx`, `tqdm`, `statsmodels`, `scikit-learn`).

## Folder naming convention

Each dataset is stored as a folder named `{Frequency}_{Type}_{Feature}_`, corresponding to the three factors in Table 1 of the paper:

| Position | Meaning | Values |
|---|---|---|
| 1st field | Drift frequency | `I` = Equal (Igual) between classes, `D` = Different between classes |
| 2nd field | Drift type | `abrupto`, `gradual`, `incremental`, `recorrente` (when the type is the same across classes), or `D` (when the type itself differs between classes) |
| 3rd field | Affected feature | `I` = Equal (Igual) between classes, `D` = Different between classes |

The 20 folders together correspond to datasets B1 through B20 as defined in Table 1 of the paper.

## Contents

Each folder contains the per-class synthetic sequences generated by `sintetico.py` for that scenario. See the script for the exact file format and columns.
